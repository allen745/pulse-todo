# Pulse — College Day Planner

Day-by-day planner built around the ADIT AI&DS Sem-3 timetable.

## Run

```bash
npm install
npm run dev
```

## Features

- Mon–Sat day tabs with your college classes preloaded
- Checkbox each class / task (resets each week)
- Add custom tasks to any day (optional time)
- Lab batch filter (1A12 / 1B12 / 1C12)
- Local persistence
